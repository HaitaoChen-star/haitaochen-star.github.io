# Book Chen Academic Website

This is a dependency-free academic website prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create a GitHub repository named `haitaochen-star.github.io`.
2. Upload all files and folders from this package to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/(root)` folder, then save.

The website will appear at `https://haitaochen-star.github.io`.

Your GitHub profile is `https://github.com/HaitaoChen-star`. Add Google Scholar, ORCID, LinkedIn, or a custom domain later if desired.
